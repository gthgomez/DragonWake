# DragonWake alpha design reference

This directory contains reference-only visual inputs for future sprite and art generation work. These files are not canonical runtime assets and must not be promoted into `apps/web/public/art/` without the provenance, evaluation, and promotion steps required by `ALPHA_VISUAL_CONTRACT_V1.md`.

`DragonWake-AlphaDesign.png` is the user-provided alpha UI/world concept capture used as visual context for sprite-generation experiments.
