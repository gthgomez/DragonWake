# Alpha R2 art requirements

The current Dragon Presence glyph and iconography are temporary vector UI
assets. They are intentionally not classified as production art.

| Asset | Surface | Requirements | Temporary replacement |
|---|---|---|---|
| Sleeping dragon presence plate | Castle first-session card | 16:9, weathered medieval stone, mostly obscured biological silhouette, low warm light, transparent edge treatment, dormant/stirring variants | `public/art/icons/icon-dragon.svg` |
| Dragon scar expedition plate | Knowledge / expedition | 16:9, scarred upland ruin, evidence-focused composition, subdued bronze/umber palette, no readable text, desktop/mobile crops | existing Knowledge CSS silhouette |
| Specialized holding plates | Castle / settlement switcher | 4:3 per holding, distinct architecture and terrain for Marcher Keep, Forest Citadel, dragon site; icon-safe focal point | existing settlement labels and CSS panels |

Generated or commissioned art must retain provenance and receive visual review
before replacing these temporary assets.
